# Рабочие ресурсы

Здесь находятся ресурсы действующей сборки. Они подключаются через TS-импорты или CSS; установленные на компьютере посетителя шрифты и внешняя папка оригиналов не нужны для запуска.

| Каталог | Назначение |
| --- | --- |
| `fonts/` | Локальные VK Sans Display/Text и Max Sans Regular/Medium/DemiBold/Bold. Max Sans WOFF2 сверены с TTF пользователя; сохраняются подключённые начертания, а не временная замена |
| `images/home/` | Изображение курсора, привязанное к координатам масштабируемого холста |
| `images/home/first-screen/` | Фон и два логотипа нового стартового экрана |
| `images/onboarding/vk-video/` | Фон, логотип, плашка и кнопка онбординга VK |
| `images/max-flow/` | Фон, логотип, карточки и управление MAX. Пользовательские надписи набраны отдельно; отдельный фон второго вопроса не применяется |
| `images/vk-flow/` | Общий фон VK, карточки, управление, текстура баббла, три фазы сканирования, native активация и сохранённый финал с QR |

Особые ресурсы:

- `images/max-flow/start.webp` – lossless crop 360 × 141 полного native PNG `4435:63573`, кнопка `4688:54732`, без надписи и декоративного курсора. Glass сохранён в исходном растре; дробное поле обрезается, надпись остаётся живой.
- `images/vk-flow/selected-drive-background.svg` – только три исходных фоновых слоя native `4527:141278` внутри `4514:130150`, с необходимыми масками и градиентами. Фон для одного подтверждённого выбранного ответа; фотографии и sample-тексты в SVG отсутствуют.

- `images/max-flow/audience-back.webp`, `back.webp`, `thanks.webp` – обрезки native PNG целого кадра MAX без надписи кнопки. Glass запечён вместе с родным фоном, поскольку самостоятельный экспорт дал тёмные артефакты. Размеры 264 × 121, 263 × 121 и 580 × 121; CSS не растягивает растр, а обрезает дробные поля до исходной области кнопки. Надписи остаются живым текстом. «Спасибо» используется как общий согласованный шаблон четырёх финалов.
- `images/vk-flow/metadata-bubble-final-clean.png` – экспорт без текста для внутренней текстуры VK-баббла. Правая граница обрезана родителем уже в источнике; один замкнутый контур воспроизводится CSS. Это адаптация к динамическим тегам, не полный Glass-эффект 1:1.
- `images/vk-flow/scan-background-final.webp`, `scan-light-contour-scenario.webp`, `scan-white-particles-scenario.webp` – три фазы одного шага сканирования; изображения не перерисованы.
- `images/vk-flow/discovery-activation-figma-clean.webp` – native кадр `4788:10640`, 1080 × 1920, без двенадцати текстов. Графика исходная; заголовок, пояснение и десять тегов живые. SVG является источником метрик, не подложкой приложения.
- Семь больших активных PNG переведены в WebP только после полного совпадения декодированных RGBA-пикселей. Среди них `final-background-polina.webp`: QR остаётся в прежнем растре 2160 × 3840. Принятые PNG сохранены во внешнем `optimized-originals/` с манифестом `optimized-originals-manifest-20261004-045159-889.json`; импорты и предзагрузка используют новые WebP.

Клиентские оригиналы находятся вне репозитория: `../../../05_Веб-прототип_исходники-2026-10-04/sources/экспорты/`. Исключённые ресурсы – в `../../../05_Веб-прототип_исходники-2026-10-04/unused-assets/src/assets/`, прежний код – в `legacy-code/` того же архива. Файлы не уничтожены, SHA-256 переноса проверены. Архив не включается в GitHub ZIP и не импортируется приложением.

Не добавлять сюда временные рендеры, аудиты, архивные копии и изображения без рабочего назначения. Пустые локальные каталоги старой структуры не входят в Git-архив.
