## Код

| Путь | Назначение |
| --- | --- |
| `src/app/` | Корневое приложение |
| `src/pages/` | Страница прототипа |
| `src/features/prototype/` | Состояния, переходы и расчёт результатов |
| `src/features/prototype/useSpeech.ts`, `speech.ts` | Синтез речи, выбор русского голоса и отмена чтения; без распознавания |
| `src/components/` | Переиспользуемые интерфейсные компоненты |
| `src/content/` | Сценарные вопросы, ответы и тексты |
| `src/types/` | Общие типы сценария |
| `src/styles/` | Стили холста 1080 × 1920 |
| `src/assets/fonts/` | Локальные шрифты |
| `src/assets/images/` | Только изображения, реально используемые приложением |
| `экспорты/` | Неизменяемые исходные PNG пользователя |

Модульные тесты лежат рядом с проверяемой логикой. Новые каталоги создавать только при появлении реального содержимого.
