## Внешний локальный архив

Корень: `../05_Веб-прототип_исходники-2026-10-04/`. Он не включается в GitHub ZIP и не требуется для установки, тестов или сборки. В приложении нет импортов из него. Для воспроизводимой передачи достаточно репозитория; для повторной сверки оригиналов используется архив или ссылки из `SOURCE_REGISTER.md`.

| Путь относительно архива | Содержимое |
| --- | --- |
| `sources/экспорты/` | Неизменяемые экспорты пользователя и сохранённые native-исходники Figma |
| `sources/бриф.m4a`, `sources/бриф_расшифровка.md`, `sources/бриф_расшифровка.txt` | Бриф и прежняя расшифровка |
| `unused-assets/src/assets/` | Ресурсы без ссылок из рабочего TS/CSS; исходные относительные пути сохранены |
| `legacy-code/src/` | Три прежних компонента и копии CSS/предзагрузки до исключения мёртвого кода |
| `documentation/PROJECT_STATE.before-cleanup-2026-10-04.md` | Полная история состояния до сокращения рабочей памятки |
| `manifest-*.json`, `transfer-plan-*.json` | План и проверенные SHA-256 перемещения клиентских оригиналов |
| `cleanup-unused-assets-sha256.json`, `cleanup-code-backup-sha256.json` | Проверяемые копии неиспользуемых ресурсов и прежнего кода |
| `optimized-originals/`, `optimized-originals-manifest-20261004-045159-889.json` | Семь активных PNG до lossless WebP; исходные относительные пути, SHA-256 и размеры сохранены |
| `replaced-max-buttons/` | Прежние текстуры двух «Назад» и «Спасибо» до исправления native Glass, с манифестами SHA-256 |

Семь больших активных PNG переведены в WebP после независимого сравнения всех декодированных RGBA-пикселей. QR 2160 × 3840 сохранён. Оригиналы и манифест находятся в `optimized-originals/`; рабочие имена перечислены в `src/assets/README.md`.
