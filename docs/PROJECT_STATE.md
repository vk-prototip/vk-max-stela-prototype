# Текущее состояние проекта

Дата обновления: 2026-09-29.

## Рабочая точка

Прототип запускается командой `npm run dev` и доступен локально по адресу `http://127.0.0.1:5173/vk-max-stela-prototype/`. Публичная сборка автоматически публикуется из ветки `main` по адресу `https://vk-prototip.github.io/vk-max-stela-prototype/`. Реализован общий стартовый экран и две полностью проходимые ветки: MAX и VK Видео.

## Реализовано

- Фиксированный портретный холст 1080 × 1920 с пропорциональным предпросмотром.
- Фоны подключены как WebP 1080 × 1920: суммарно 314 462 байта вместо 5 693 506 байт PNG. Стартовый фон предзагружается из HTML с высоким приоритетом; после загрузки первого экрана заранее загружаются и декодируются фоны обеих веток, «назад», MAX-кнопка и изображение результата. Исходные PNG не менялись.
- Стартовый экран на фоне Figma: один вопрос и два логотипа VK Видео и MAX без старых рекламных карточек.
- По указанию пользователя логотип «Цифровые решения» со стартового экрана удалён 2026-09-28.
- Отдельный онбординг каждой ветки после выбора логотипа. «НАЧАТЬ» открывает вопросы; «назад» из первого вопроса возвращает к онбордингу, затем к выбору продукта.
- Онбординги обновлены по структуре Google Docs 2026-09-29: «Исследуй свои возможности с MAX!» и три шага, «Исследуй мир вместе с VK Видео!» и два шага. После следующего замечания пользователя композиция уточнена: VK Sans Display 76 px для заголовков, VK Sans Text 52 px для действий и 32 px для меток шагов. Шаги используют всю ширину 904 px, разделены тонкими горизонтальными линиями; основной блок центрирован в доступной зоне вместо большого пустого промежутка. Нижний блок начала сохранён, без карточек, карусели и микрофона.
- Приветствие «Добро пожаловать в экосистему VK. Здесь лента подстраивается под тебя» теперь только произносимая реплика, а не экранный заголовок. Новая редакция документа заменяет прежнее оформление приветствия и вводные абзацы. Вход с новой загрузки всегда открывает вопрос и два логотипа; после проверки оставлять публичную вкладку на этом экране.
- Мобильный холст измеряется по фактическому контейнеру с `100dvh` и safe-area, размер отслеживает `ResizeObserver`. Документ не прокручивается и не создаёт лишнюю высоту от внутреннего холста 1920 px; холст обрезает только невидимую область до масштабирования, видимое содержимое целиком сохраняется.
- MAX: два вопроса, назначение одной из четырёх миссий и переход к правой панели.
- VK Видео: пять вопросов с четырьмя ответами в каждом, прежний подсчёт тематик и случайное разрешение равных баллов, необязательная имитация оцифровки и переход к левой панели. Четвёртый ответ первого вопроса: «Спорт в любом формате», добавлен по запросу пользователя 2026-09-28 с прежними весами спортивного ответа. Заглавная буква исправлена по следующему уточнению пользователя.
- 2026-09-28 повторно сверена вкладка Google Docs: обновлены вопросы 1–4 VK Видео, четыре ответа второго вопроса и название миссии «Общение на максимум». В третьем вопросе исправлен пропуск предлога «на». По последующим прямым уточнениям пользователя вопрос о фото сокращён до «Сделаем фото?» 2026-09-29, ответ второго вопроса: «Остроумные ведущие». Q-011 закрыт. Веса ответов и маршруты сохранены.
- Проведена корректура всех видимых текстов по запросу пользователя: «Узнай, как…» с запятой, MAX везде латиницей. Остальные формулировки, согласованная пунктуация подписей и переносы сохранены.
- По подтверждению пользователя 2026-09-29 добавлена базовая озвучка браузером. Выключена по умолчанию, включается кнопкой динамика, читает реплики и вопросы (без списка ответов), отменяет старую фразу при переходе и скрытии вкладки. Выбирается русский голос, предпочтительно локальный; при отсутствии голоса кнопка сообщает об этом в доступном названии и подсказке. На проверяемом компьютере браузер предоставил только английские голоса: реальное звучание русского голоса здесь не подтверждено. Распознавание и устные уточнения MAX не подключены.
- Кнопка «назад» расположена под вариантами и использует цельный экспорт Figma.
- MAX-кнопки при наведении только слегка высветляются внутри собственного периметра.
- В живом интерфейсе используются локальные VK Sans; MAX временно использует те же семейства по указанию пользователя.
- Стартовый вопрос не обрезается; системный курсор заменён изображением `экспорты/стела/image 2105.png` размером 233 × 197 px в координатах холста и масштабируется только вместе с холстом.
- После «Да, давайте» нет дополнительного декоративного значка.
- Описание фото из документа 2026-09-29: «На его основе превратим тебя в главного героя твоей персональной подборки», в три смысловые строки. Направления к обеим панелям разбиты на две строки после запятой. На финале MAX вместо стрелки кнопка «Подобрать другую миссию», возвращающая к первому вопросу MAX.
- Проведён аудит типографики всех текстовых экранов. В онбордингах переносы по смысловым фразам, «персональную подборку» не разрывает. Заголовки вопросов используют ширину 904 px, две фразы пятого вопроса разделены переносом. На финале MAX слово «Миссия» отделено от названия, «с Цифровым ID» и «на максимум» целиком на строке, пояснения 36 px с балансировкой строк.
- Слово «Миссия» 76 px на отдельной строке, все названия тоже 76 px: одна строка, либо две для длинных. Пояснения 36 px на ширине 904 px, одна строка при достаточном месте, иначе две без уменьшения шрифта. В новых шагах онбординга не разрываются «миссию в MAX» и «от технологии Discovery».
- Логика маршрутизации, подсчёта и актуальная редакция текста покрыты модульными тестами.
- Настроен автоматический деплой production-сборки на GitHub Pages.
- Для локального запуска двойным кликом добавлен `start-prototype.bat`; он устанавливает зависимости при необходимости, запускает Vite и открывает браузер.
- Финальный экран VK Видео сообщает об активации Discovery, направляет посетителя к левой панели и завершается кнопкой «спасибо».

## Проверка базовой версии

На момент фиксации успешно выполнены:

- `npm run typecheck`
- `npm run test` – 15 тестов
- `npm run lint`
- `npm run build`

После обновления текстов проверены новый старт, оба онбординга, прохождение MAX и VK Видео, возврат к онбордингам, пропуск оцифровки и сброс. Геометрия проверена на 1080 × 1920, визуально на 432 × 768 и 1440 × 900. Изображения загружены, новые тексты используют VK Sans, ошибок браузера нет. Hover старых MAX-кнопок и имитация оцифровки не изменялись.

После оптимизации проверена production-сборка без кэша: все три WebP и изображения следующих экранов получили HTTP 200 ещё на стартовом экране, до выбора ветки. Визуально проверены все три фона. Предзагрузка не блокирует нажатия и игнорирует ошибки декодирования.

2026-09-29: новый онбординг проверен на 320 × 568, 390 × 844 и 1440 × 900. При попытке прокрутки scrollY остаётся 0, scrollHeight совпадает с высотой окна. Проверены новая подпись фото, включение/отключение звука и ошибка отсутствия русского голоса. Очередь реплик и отмена при переходе проверены временным тестовым движком в отдельной вкладке; после проверки подмена удалена перезагрузкой. Реальный звук русского голоса и мобильный Safari не проверены из-за отсутствия соответствующего голоса и устройства.

## Нельзя додумывать

- Новые тексты, переходы, миссии и функции без источника или прямого указания пользователя.
- Физический размер дисплея и оборудование стенда.
- Реальную передачу результата на стены или внешние системы.
- `Max Sans`: до передачи файла применяется согласованная замена VK Sans.
