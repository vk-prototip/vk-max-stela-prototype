## Рабочая точка

React, TypeScript, Vite; портретный холст 1080 × 1920 масштабируется под доступное окно. Запуск: `start-prototype.bat` или `npm install` и `npm run dev`, Node.js 24+. Адрес: <http://127.0.0.1:5173/vk-max-stela-prototype/>. Все рабочие ресурсы и обязательные правила входят в репозиторий; соседние папки и установленные шрифты не нужны получателю GitHub ZIP.

Выпуск включает обновлённую механику, сверку дизайна, организационную уборку и исправления D-063. Публичный адрес: <https://vk-prototip.github.io/vk-max-stela-prototype/>. Точный опубликованный commit и статус сборки проверяются в GitHub Actions. `?v=...` не выбирает историческую версию исходников.

Для публикации текущая рабочая версия фиксируется в Git и отправляется в `main`. При продолжении работать в этой папке, проверять `git status`, не переключать ветки и не сбрасывать изменения.

## Маршруты и данные

- Общий вход: вопрос и два логотипа, короткий кадр логотипа выбранного продукта, затем онбординг. Начало всегда открывается при новой загрузке. Задержка логотипа 1,2 с – настройка прототипа, не тайминг клиента.
- MAX: два вопроса, после каждого остаётся выбранная карточка и появляются её восемь тегов. Для бизнеса любая цель назначает «Продвижение бизнеса»; для личного пользования три цели дают три разные миссии. У целей отдельные массивы метаданных для двух аудиторий. Финал возвращается к двум логотипам через «Спасибо» или касание остальной области; автоматического таймера нет.
- VK Видео: три вопроса. Первые два независимо начисляют баллы восьми тематикам видео и жанрам ИИ-обложек. Третий не добавляет баллы, а задаёт одну из четырёх структурированных инструкций Discovery. При ответе публикуется одно событие, анимация тегов не отправляет его повторно.
- Базовый пул – top 3, прямо подтверждённый сценарием. Равенство на границе разрешается случайно один раз. В условии «из тематики 3 или 4» участвуют только положительные темы: нулевая rank4 диагностического рейтинга исключена.
- На каждую выбранную тему вычисляется жанр ИИ-обложки по отдельным весам. Распределение фиксируется до дальнейших переходов. Базовый план продюсера: по два видео на тему и одна генерация при фото. Максимум 12 единиц – верхняя граница, не обязательный объём. Совместное включение сюрприза Discovery в этот план остаётся Q-018; `contentPlan` и `discoveryInstruction` передаются отдельно, с `relationToContentPlan: unconfirmed`.
- Фото необязательно. Согласие: метаданные фото, камера, три фазы сканирования внутри одного состояния, активация и финал. Пропуск: пустые метаданные фото, активация и финал. Выбор М/Ж и поле `gender` удалены.
- Активные условия открывают прежнюю выдвижную панель поверх фото, без сдвига фона. «Да, давайте» и обращение на «вы» в уведомлении сохранены. Внутри панели демонстрационный текст, не утверждённые условия.
- Контракт событий `version: 2`: браузерное событие `vk-stela:event` и `BroadcastChannel('vk-stela')` в пределах одного сайта. Внешние экраны, доставка с подтверждением, каталог видео, камера, генерация, голос и озвучка не подключены. Вычисленный план не означает, что изображения или видео созданы.

Полные контракты, таблицы, правила пересчёта и миграция находятся в `MECHANICS.md` и `AI_COVERS.md`; пользовательские тексты и статусы происхождения – в `src/content/`.

## Визуальная реализация

- Для VK сохраняются согласованные «Чтобы был драйв и азарт» и новая пара на синем диване, независимо от старых подписей макета. Финал с прежним QR сохранён; новый финал Figma исключён. Направление к левой панели без точки.
- Активация взята из Figma `4788:10640`: native фон без двенадцати текстовых слоёв, живые заголовок и пояснение, десять реальных уникальных тегов. Порядок данных не меняется; визуальные рамки назначаются по длине, чтобы длинные надписи не обрезались.
- Сканирование использует три исходные фазы: синий силуэт, светлый контур, белые частицы. Кадр с фотографией девушки исключён пользователем. Времена 2,4 с сканирования и 3,2 с активации – настройки прототипа. При reduced motion показ стабилен, теги не пропадают.
- MAX использует Max Sans из файлов пользователя там, где его задаёт Figma; слои VK Sans остаются VK. Заголовок MAX-онбординга отсутствует по комментарию источника. Оба вопроса MAX используют общий фон без отдельного розового круга.
- Обе «Назад» и «Спасибо» MAX переэкспортированы из целого native кадра без текста: устранён тёмный артефакт отдельного экспорта Glass, растр не растягивается. Направление к правой панели стоит в одну строку на y986,23; «Спасибо» на y1051,41. Семь крупных PNG заменены lossless WebP, все RGBA-пиксели и размеры совпадают с оригиналами, включая QR.
- «Начать» MAX также использует native Glass из целого кадра: обрезка 360 × 141 без надписи, дробное поле обрезается CSS. Плашки метаданных сдвигаются внутрь холста по фактической ширине после загрузки шрифта. Первые две строки Цифрового ID сдвинуты на −4,5 px. Радиус карточек VK – 60 px; tracking 0,01em у трёх рамок активации учитывается при подборе размера текста.
- Тёмный native фон применяется только к выбранному ответу «Чтобы был драйв и азарт», для которого текущая Figma подтверждена. Из SVG сохранены базовая заливка, градиент и группа точек; фотография, подпись и динамические бабблы приложения остаются согласованными адаптациями. Остальным выбранным ответам этот фон автоматически не назначен.
- Native SVG/PNG и настоящие контуры шрифтов использованы для повторной сверки рамок, baseline и интервалов. Коррекция измеренной плотности сглаженных краёв применяется только к проверенным живым текстовым слоям; семейство и вес не подменяются. Это не гарантия попиксельного совпадения на любых браузерах или DPR и не утверждение CSS Glass 1:1.

Точные действующие метрики, согласованные исключения и ограничения переноса – в `FIGMA_UI_REFERENCE.md`. Исторические разделы ниже актуальной сверки в этом файле не имеют приоритета.
