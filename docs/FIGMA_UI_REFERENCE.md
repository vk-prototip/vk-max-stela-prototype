Дата проверки: 2026-09-27.

## Источник

- Файл: Figma Design `VK ЦР 2026 | main`.
- Страница: `Стела`.
- Выделение пользователя: `1:3`.
- Основной экран внутри выделения: `2250:2538`.
- Целевой размер экрана: 1080 × 1920.

Этот источник определяет композицию, графику, размеры и типографику. Сценарные тексты берутся из актуального сценария и прямых указаний пользователя, а не заменяются текстами из визуального макета.

## Шрифты

- Центральный вопрос стартового экрана: `Montserrat SemiBold`, 30 px, как в узле `2082:8251`.
- Для Montserrat подключён локальный вариативный файл из официального репозитория Google Fonts.
- Весь текст внутри двух кнопок сохраняется как часть исходных PNG и не набирается в HTML.

## Локальные ресурсы

- `экспорты/` – исходные PNG, переданные пользователем из Figma.
- `src/assets/images/` – только подключённые рабочие копии экспортов, разложенные по назначению.
- Фоны общей стелы, ветки VK Видео и ветки MAX подключены как полноэкранные изображения 1080 × 1920.
- Кнопки `Group 2131329276.png` и `Group 2131329277.png` используются целиком, без разборки на фон, текст и графику.
- Кнопка «назад» используется целиком из Figma-экспорта, чтобы сохранить точные начертание, свечение и пропорции оригинала.
- Остальные интерфейсные надписи набраны живым текстом с локальными VK-шрифтами.
