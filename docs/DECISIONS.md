## D-010. Только подтверждённые надписи

- Дата: 2026-09-27
- Статус: принято пользователем
- Решение: не показывать на экранах подписи, которых нет в FigJam, Google Docs или прямых указаниях пользователя. Убрать служебные названия, нумерацию вопросов, подпись о выборе миссии и неподтверждённые тексты кнопок.
- Основание: прямое указание пользователя.
- Техническое уточнение: навигационные кнопки без видимого текста сохраняют невидимые названия для программ экранного доступа.

## D-015. Новый вход и синхронизация с Google Docs

- Дата: 2026-09-27.
- Статус: согласовано пользователем.
- На старте один вопрос и два логотипа. После выбора продукта отдельный онбординг, затем вопросы по кнопке «НАЧАТЬ». Это заменяет старые стартовые PNG-карточки из D-014.
- Тексты обеих веток заменены актуальными из вкладки `ТЕКСТ основной`, точная версия зафиксирована в `GOOGLE_DOC_COPY.md`. Из альтернатив взяты два явно выбранных пользователем текста.
- В первом вопросе VK Видео теперь три ответа; веса оставшихся ответов и назначение миссий MAX не изменены.
- Финалы направляют к правой/левой панели; новая формулировка VK Видео заменяет текст финала из D-004. Необязательная имитация оцифровки сохранена.
- Все живые тексты, включая стартовый вопрос и онбординг, используют VK Sans. Подключение Montserrat из стартового экрана удалено.
- Голос отложен отдельным ответом пользователя: сейчас экраны и нажатия. Подсказка показана для демонстрации сценария, устные уточнения MAX будут подключаться на голосовом этапе.
