# Веб-прототип стенда VK и MAX

Интерактивный прототип на React, TypeScript и Vite. Внутренний холст фиксирован на 1080 × 1920 и пропорционально масштабируется под окно браузера.

Публичная версия: <https://vk-prototip.github.io/vk-max-stela-prototype/>

## Запуск

В Windows можно запустить прототип двойным кликом по `start-prototype.bat`. При первом запуске батник установит зависимости, запустит локальный сервер на фиксированном порту 5173 и откроет браузер.

Запуск из терминала:

```powershell
npm install
npm run dev
```

Проверка перед передачей:

```powershell
npm run typecheck
npm run test
npm run lint
npm run build
```

## Вход в проект без истории диалога

1. Прочитать `../AGENTS.md` и локальный `AGENTS.md`.
2. Открыть `docs/PROJECT_STATE.md` – там зафиксирована текущая рабочая точка.
3. Открыть `docs/CHANGELOG.md` – там сохранён путь от инициализации до текущего состояния.
4. Проверить `docs/OPEN_QUESTIONS.md` перед изменением логики или текста.
5. Использовать `docs/NAVIGATION.md` как карту кода и источников.
6. Для передачи проекта разработчикам прочитать `docs/MECHANICS.md`: там маршруты, таблица баллов, контракт событий и границы интеграции.

## Данные для других экранов

Каждый ответ публикует событие с метаданными. В локальном прототипе его получают обработчик `vk-stela:event` в текущей вкладке и `BroadcastChannel('vk-stela')` в другой вкладке того же сайта. Внешние экраны инсталляции пока не подключены: адрес и протокол передачи должны быть согласованы отдельно. Формат событий, пример подписки и правила пересчёта описаны в `docs/MECHANICS.md`.

Пользовательские исходники находятся в `экспорты/` и не редактируются. В `src/assets/` хранятся только подключённые рабочие копии.
